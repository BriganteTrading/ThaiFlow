# ThaiFlow A0–A2 · 4.000 Lernkarten

Diese Version enthält 4.000 Lernkarten. Sie kombiniert häufigen Grundwortschatz, Funktionswörter, feste Wendungen, Kollokationen, Frage-/Antwortmuster und strukturierte Übungssätze.

Wichtig: 4.000 Lernkarten sind nicht gleichbedeutend mit 4.000 einzigartigen Wortstämmen. Für A0–A2 ist das pädagogisch sinnvoll, weil CEFR-Kompetenz auch den Gebrauch von Phrasen, Routinen und einfachen Satzmustern umfasst. Der CEFR beschreibt A1 als grundlegende Sprache für konkrete Bedürfnisse und A2 als routinemäßige Alltagssituationen. citeturn0search12turn0search16

Für Thai gibt es beim Council of Europe derzeit keine offizielle sprachspezifische Reference Level Description wie für einige andere Sprachen. Deshalb ist die ThaiFlow-Kategorisierung ein praxisorientierter A0–A2-Lehrplan, keine offizielle Thai-CEFR-Wortliste. citeturn0search0turn0search1

## Audio
Die aktuelle Version nutzt die Browser-Web-Speech-API. Für eine Premium-Version sollten echte/lizenzierte Thai-Aufnahmen oder professionelles TTS eingebunden werden.

# ThaiFlow A0–A2 · 1.050 Lernkarten

Diese Version enthält **1.050 Lernkarten**:
- A0: Grundlagen / Überleben
- A1: Alltag und einfache Routinen
- A2: Routinen, Beschreiben, Begründen und häufige Satzmuster
- Einzelwörter plus feste Satzbausteine / häufige Chunks

Der CEFR beschreibt A1 und A2 ausdrücklich nicht nur über einzelne Wörter, sondern über kommunikative Handlungen, Wortschatzumfang, Routinen und einfache Satzmuster. Deshalb enthält die App neben Lexik auch viele wiederverwendbare Satzbausteine. citeturn0search2turn0search7

## Browser / iPhone
Auf eine HTTPS-Webseite hochladen → in Safari öffnen → Teilen → Zum Home-Bildschirm.

## Audio
Die App verwendet die Browser Web Speech API und sucht explizit nach einer Thai-Stimme. Für eine finale kommerzielle Version sollten hochwertige lizenzierte Thai-Aufnahmen oder professionelles TTS eingebunden werden.

## Hinweis zur Einstufung
CEFR ist ein Kompetenzrahmen, keine universelle feste Wortliste für Thai. Die Karten sind daher als praxisorientierter A0–A2-Lehrplan gedacht, nicht als offizielles CEFR-Thai-Wörterbuch. citeturn0search1turn0search6
